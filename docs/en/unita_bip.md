# Academic & Institutional Framework — UNITA Erasmus+ BIP & STUCOM Pelai
**Datacycle · Unit 1 · Case 2: Retail Banking Real-Time Fraud Detection**

This project represents the primary deliverable for the **Datacycle course (Design the Data Lifecycle of a Real Company)**, engineered at **STUCOM Pelai (Barcelona, Spain)** as part of the **UNITA Erasmus+ Blended Intensive Programme (BIP)** 2026–2027.

### Core Project Standards:
1. **English as Working Language**: All source code, commit history, technical documentation, and API specifications are maintained strictly in English to mirror global software engineering environments.
2. **Real-World Industry Problem-Solving**: Building resilient data architectures that simulate enterprise retail banking transaction loads while respecting GDPR and PSD2 payment directives.
3. **Enterprise Engineering Practices**: Strict Git version control, GitHub Actions CI automation, Docker containerization, and automated unit testing.

---

## 3. Alignment with MOPT2 Module Objectives

The **Python for Artificial Intelligence (MOPT2)** curriculum requires students to architect and deploy an end-to-end AI system:
- **Advanced Data Processing**: Efficient manipulation of tabular and semi-structured datasets using Pandas, PyArrow, and Apache PySpark.
- **Feature Engineering**: Calculation of Haversine spatial distances, backward-looking velocity windows without data leakage, and behavioral spending z-scores.
- **Predictive Machine Learning**: Supervised training, class-imbalance reweighting, and threshold optimization using LightGBM and Scikit-learn.
- **Real-Time Serving & Visual Analytics**: Sub-millisecond REST inference endpoints with FastAPI and reactive command-center dashboards using Streamlit and Plotly.
