# UNITA Erasmus+ BIP Presentation Materials

This folder contains the presentation slides and institutional documentation for the **UNITA Erasmus+ Blended Intensive Programme (BIP)** 2026–2027.

---

## 📌 Context & European Consortium

The **UNITA Erasmus+ BIP Programme** combines online collaborative research, hands-on data engineering, and an international mobility experience. The project simulates a global enterprise tech environment using English as the unified working language.

### Participating Institutions & Countries:
- 🇪🇸 **Spain**: STUCOM Pelai (Barcelona) — DAW 2 (Web Applications Development), Module MOPT2 (Python for Artificial Intelligence).
- 🇵🇹 **Portugal**: Higher Education Partner Institutions.
- 🇨🇭 **Switzerland**: Higher Education Partner Institutions.
- 🇷🇴 **Romania**: Higher Education Partner Institutions.

### Core Technical Pillars:
1. **Data Engineering**: Scalable Medallion architectures (Bronze, Silver, Gold) with PySpark and partitioned Parquet.
2. **Business Intelligence**: Actionable KPI dashboards, real-time telemetry, and financial ROI models.
3. **Machine Learning & Analytics**: Gradient boosted tree classifiers (LightGBM), threshold optimization, and spatial/velocity feature engineering.
4. **ETL & Data Lifecycle**: Sub-second streaming event ingestion, automated quality assurance gates, and regulatory cold archival.
